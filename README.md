# Calendário de Feriados — BrasilAPI

Aplicação web desenvolvida para consultar os feriados nacionais brasileiros de um determinado ano, utilizando a BrasilAPI.

## Funcionalidades

- Consulta de feriados nacionais por ano.
- Preenchimento automático do ano atual.
- Exibição dos feriados em uma tabela com data, dia da semana e nome.
- Contagem do total de feriados encontrados.
- Destaque dos feriados que caem aos sábados e domingos.
- Identificação do próximo feriado e quantidade de dias restantes.
- Tratamento de erros durante a consulta.
- Layout responsivo para celulares, tablets e computadores.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- BrasilAPI

## API utilizada

A aplicação utiliza a BrasilAPI para consultar os feriados nacionais.

Endpoint:

`https://brasilapi.com.br/api/feriados/v1/{ano}`

Documentação: https://brasilapi.com.br/

## Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
4. Informe o ano desejado e clique em **Consultar Feriados**.

## Projeto acadêmico

Atividade desenvolvida para a disciplina de Programação para Internet, com o objetivo de praticar o consumo de APIs REST, a manipulação de arrays com `forEach()` e a atualização dinâmica de elementos HTML utilizando JavaScript.
